Leadwort.Manga.Runtime.Core.MangaSettings Struct Reference
Classes

Artist controls for the manga filter. The filter runs in four stages: edge flow, abstraction (orientation-aligned bilateral filter), ink lines (flow-based XDoG with cleanup) and screentones.

Public Attributes

float FlowSmoothness
 How smooth the detected edge directions are. Higher values give longer, more coherent lines.
int AbstractionPasses
 Number of smoothing passes. More passes remove texture before lines and tones are drawn.
float SmoothingSize
 Size of the smoothing, in pixels.
float ColorTolerance
 How different two colors can be and still be smoothed together.
float LineWidth
 Width of the ink lines, in pixels.
float LineSensitivity
 How many edges become lines. Higher values draw more, fainter edges.
float LineThreshold
 How much ink is drawn. Higher values detect more and fuller lines.
float LineCleanup
 Removes lines on weak edges and short fragments, for clean contours.
float LineCoherence

float LineCrispness
 Hardness of the line edges. Low values give soft, pencil-like lines.
