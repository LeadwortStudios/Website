Package description

Manga Filter is a real-time post-processing effect that turns your game into a printed manga page: flowing ink lines, solid blacks and real screentones. It is based on research in line drawing and manga screening (Flow-Based Image Abstraction, Kang et al. 2009; XDoG, Winnemöller et al. 2012; Richness-Preserving Manga Screening, Qu et al. 2008), adapted to run every frame. It works with both the Built-In Render Pipeline and URP (Universal Render Pipeline), with full support for the Render Graph API of Unity 6 (URP 17).

How it works

Each frame the filter runs five stages, all configured through MangaSettings:

  • Edge Flow - detects the direction of the edges in the image (smoothed structure tensor). Lines are drawn along this flow, so they stay long and coherent.
  • Abstraction - removes texture and noise with an edge-preserving smoothing aligned to the flow (orientation-aligned bilateral filter), keeping clear shapes.
  • Ink Lines - a flow-based extended difference of Gaussians (XDoG) draws the lines. Ink Fill also fills the darkest areas with solid ink, and Line Cleanup removes specks and short fragments.
  • Screentone & Paper - lightness is split into a few tone levels and printed as a screentone pattern. Mixed By Color gives each hue its own pattern, so colors with the same lightness stay distinguishable in black and white.
  • Temporal Stability - blends with the previous frame (reprojected with the depth buffer) so lines and tones don't flicker in motion.

Where it lives in your project

Depending on your render pipeline, you'll attach a different component:

Pipeline Component
Built-In Render Pipeline MangaPostProcess (Camera component)
URP (Render Graph) MangaPostProcessFeature (Renderer Feature)

Both share the same MangaSettings and MangaPreset assets, so presets work in either pipeline.
