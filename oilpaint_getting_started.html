Getting Started

1. Add the component

Built-In Render Pipeline: Add the OilPaintPostProcess component directly to your Camera.

Universal Render Pipeline (URP): Open your active Universal Renderer Data asset, click Add Renderer Feature and choose Oil Paint Post Process Feature.

You can also open one of the sample scenes in Samples/. For the URP sample, assign Samples/Resources/URP/URP 17 Oil Paint Renderer in Project Settings > Graphics, or add the feature to your own renderer.

2. Start from a preset

In the Preset Manager at the top of the Inspector, drag one of the presets from Samples/Presets into Active Preset and click Load:

3. Tune the look

Settings are grouped in the same order as the stages of the filter. Every field has a small reset button next to it to instantly restore its default value.

  • Stroke Flow - Flow Smoothness makes strokes follow large shapes instead of small details. Flat Area Threshold and Flat Area Stroke Angle control how flat regions (skies, walls) are painted.
  • Abstraction - Brush Size is the most impactful setting: the size of the paint dabs. Abstraction Passes repeats the filter for a more abstract result (0 disables it).
  • Color - Color Levels sets the size of the palette. Quantization Sharpness goes from soft blending to hard bands. Color Smoothing rounds region boundaries along the strokes.
  • Brush & Canvas - Bristle Density and Stroke Length shape the bristle grooves. Relief Strength sets the thickness of the paint (0 = flat). Canvas Strength shows a woven canvas.
  • Varnish & Light - Specular and Shininess control the highlights. Light Angle and Light Elevation set where the light on the canvas comes from.

4. Save your look as a Preset

Once you're happy with a set of values, you can save them for reuse:

  1. In the Preset Manager section at the top of the Inspector, click Create New Preset Asset.
  2. Give it a name, this creates an OilPaintPreset asset in your project.
  3. Use Save to store your current settings into the preset, or Load to apply a preset's settings to the current component.

This is the easiest way to share a consistent painterly look across multiple cameras, scenes and render pipelines.

5. Temporal Stability

Screen-space painting filters react to every small change between frames, so without help strokes can "boil" when the camera moves. Temporal Stability (default 0.8) blends the current frame with the previous one, reprojected with the depth buffer and the camera motion. History that no longer matches the current frame is rejected (variance clipping), so moving objects don't leave trails.

  • Higher values are steadier but slightly softer during very fast motion. Set it to 0 to disable it, for example on static images.
  • It needs the camera depth texture. The component and the renderer feature request it automatically.

Tip: the filter amplifies any flicker that already exists in your scene. For the cleanest result, enable anti-aliasing (MSAA) and soft shadows, and use alpha clipping (cutout) instead of transparency for foliage. Transparent leaves don't write depth and their draw order changes with the camera.

6. Performance tuning

If you need more headroom, look at the Performance section:

  • Stylization Scale - runs abstraction and color at half or quarter resolution, then upscales. This is the biggest performance lever and gives a chunkier paint. The brush relief stays at full resolution, so strokes remain crisp.
  • Flow Field Scale - lowers the resolution used to detect stroke direction. Cheaper, with minimal visual impact.
  • Abstraction Passes and Brush Size - the abstraction stage is the most expensive one. Use fewer passes or smaller brushes on low-end hardware. The Mobile preset is a good starting point.

7. Capture a screenshot

The Utility Tools section lets you capture a high-resolution screenshot of the painted result directly, at up to 4x your Game View resolution - handy for portfolio shots or marketing material.

Notes & limitations

  • By default the effect is injected Before Rendering Post Processing, so bloom, tonemapping and color grading are applied on top of the painting. Colors are clamped to the 0-1 range inside the filter.
  • The brush texture is generated in screen space, so in motion the bristle grooves stay aligned to the screen rather than to objects. Temporal Stability keeps this calm in practice.
  • Orthographic cameras assume a static view for Temporal Stability.
