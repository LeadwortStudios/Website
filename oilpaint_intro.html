Package description

Oil Paint Filter is a real-time post-processing effect that turns your game into a moving oil painting. It is based on the research paper "Image Stylization by Interactive Oil Paint Filtering" (Semmo et al., 2016), adapted to run every frame. It works with both the Built-In Render Pipeline and URP (Universal Render Pipeline), with full support for the Render Graph API of Unity 6 (URP 17).

How it works

Each frame the filter runs five stages, all configured through OilPaintSettings:

  • Stroke Flow - detects the direction of the edges in the image (structure tensor). Every following stage paints along this flow. In flat regions, such as a clear sky, strokes use a constant direction instead of random curls.
  • Abstraction - simplifies the image into flat, edge-aligned dabs of paint with an anisotropic Kuwahara filter.
  • Color - quantizes lightness into bands in CIE-Lab space (a limited palette), adjusts saturation and smooths colors along the strokes.
  • Brush & Varnish - builds a height field of bristle grooves along the flow and lights it: diffuse shading for the relief and specular highlights for the varnish. An optional woven canvas can show through.
  • Temporal Stability - blends with the previous frame (reprojected with the depth buffer) so strokes don't flicker in motion.

Where it lives in your project

Depending on your render pipeline, you'll attach a different component:

Pipeline Component
Built-In Render Pipeline OilPaintPostProcess (Camera component)
URP (Render Graph) OilPaintPostProcessFeature (Renderer Feature)

Both share the same OilPaintSettings and OilPaintPreset assets, so presets work in either pipeline.
