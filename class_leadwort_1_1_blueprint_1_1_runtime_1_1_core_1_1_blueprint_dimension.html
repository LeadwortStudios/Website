Leadwort.Blueprint.Runtime.Core.BlueprintDimension Class Reference
Classes

Add this component to any object to draw a dimension line (with its measurement) over it when the Blueprint Filter is active and Show Dimensions is on. It measures the world-space bounds of the renderers of the object and its children, or the distance between two transforms.
